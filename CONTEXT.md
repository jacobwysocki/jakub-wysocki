# Portfolio Experience

This context describes how visitors explore Jakub Wysocki's work and how the two portfolio presentations expose the same verified facts.

## Language

**Portfolio Visitor**:
A person evaluating Jakub's work, experience, or fit and looking for trustworthy evidence quickly.
_Avoid_: User, Recruiter

**Simple Mode**:
The linear, document-style presentation of the portfolio.
_Avoid_: Normal mode, Basic mode

**Desktop Mode**:
The operating-system-inspired presentation of the portfolio, with apps, windows, a dock, and a mobile sheet adaptation.
_Avoid_: OS mode, Advanced mode

**Desktop App**:
A named portfolio experience that opens in a window in Desktop Mode and a sheet on small screens.
_Avoid_: Component, Window

**App Catalog**:
The canonical set of Desktop Apps and their presentation, placement, and launch metadata.
_Avoid_: Registry, App list

**Portfolio Location**:
A presentation-independent address for a meaningful place in the portfolio, such as a role, project, or contact view.
_Avoid_: App ID, URL, Route

**Portfolio Knowledge**:
The curated, bilingual set of facts that the portfolio is prepared to assert about Jakub and his work.
_Avoid_: Content dump, Vector database, Training data

**Knowledge Entry**:
One independently supportable fact in Portfolio Knowledge, with a stable identity and at least one Portfolio Location.
_Avoid_: Chunk, Document

**Ask Jakub**:
The grounded portfolio guide that helps a Portfolio Visitor understand Jakub's work and navigate to supporting evidence. It does not impersonate Jakub or act as a general-purpose assistant.
_Avoid_: Jakub clone, AI Jakub, General chatbot

**Evidence Link**:
A visitor-visible reference from an Ask Jakub answer to a trusted Portfolio Location that supports the answer.
_Avoid_: Citation URL, Model link

**Suggested Question**:
A curated prompt that shows a Portfolio Visitor what Ask Jakub can answer from Portfolio Knowledge.
_Avoid_: Prompt chip, Quick reply

**Spotlight**:
The deterministic, bilingual Desktop Mode search that discovers Desktop Apps and Portfolio Knowledge locally, then opens a validated Portfolio Location.
_Avoid_: AI search, Global search

**Conversation Session**:
The temporary, single-language exchange between a Portfolio Visitor and Ask Jakub during one Desktop Mode visit.
_Avoid_: Account, Chat history

**Provider-disabled state**:
The safe Ask Jakub operating mode in which the guide and direct portfolio navigation remain available but no external model call can run.
_Avoid_: Broken chatbot, Demo answer
